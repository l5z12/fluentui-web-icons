01 / REGISTER

Only the icons you need.

Import families individually for a smaller bundle. Each family includes all available sizes and styles, including color.

import { defineFluentIcon, registerIcons }
  from 'fluentui-web-icons';
import mail from 'fluentui-web-icons/icons/mail';

registerIcons(mail);
defineFluentIcon();
02 / USE

A little more color.

Color icons preserve their original palette, gradients, and shadows. Give meaningful icons an accessible label.

<fluent-icon
  name="mail"
  variant="color"
  size="24"
  label="Inbox"
></fluent-icon>
03 / EXPLORE

The whole catalog, on demand.

The auto entry registers the element and loads requested icon families as separate modules. No external CDN requests.

import 'fluentui-web-icons/auto';

// Preload before it appears on screen:
import { loadIcon } from 'fluentui-web-icons';
await loadIcon('mail');
04 / CUSTOMIZE

Part of your design system.

Regular and filled icons inherit your text color. The demo itself uses Fluent UI buttons, inputs, dropdowns, fields, badges, and theme tokens.

fluent-icon {
  color: var(--colorBrandForeground1);
  --fluent-icon-size: 1.5rem;
}

<fluent-icon name="arrow-left" flip-rtl>
